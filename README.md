# IndiaTravelPatterns

This repository provides the dataset and additional information for the article "Analyzing Census Data for Patterns of Mobility Inequity: Gender, Geography, and Public Policy in India" to be published in the Annals of Operations Research (DOI: 10.1007/s10479-025-06972-3) by Bismark Singh. This repository will be continuously updated. Here, we provide the underlying raw and cleaned datasets that are taken from India's 2011 Census. The appendix document provides graphs for the travel patterns in all the states and union territories of India.
